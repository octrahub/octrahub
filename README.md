# octrahub

Community-made directory for the Octra ecosystem.

## Pages

- `index.html` — main ecosystem directory
- `knowledge.html` — knowledge base
- `scan.html` — lite explorer-style view

## Cloudflare Pages

Use these settings:

- Framework preset: `None`
- Build command: leave empty
- Build output directory: `/`

## Domain

Replace `https://octrahub.com` in:

- `index.html`
- `knowledge.html`
- `scan.html`
- `robots.txt`
- `sitemap.xml`

## Analytics

Add the Umami tracking script before `</head>` in each HTML page.
